# Problem Filter

When the user proposes a product idea, evaluate the real human problem before suggesting features. Ask for a recent incident, the current workaround, the cost of failure, and existing tools tried.

Score pain, recurrence, existing behaviour, failure, user pull, competitive gap, outcome, build wedge, trust, and expansion from 0 to 5. Return one of: Build candidate, Validate first, Narrow the wedge, Reject, or Insufficient evidence.

Do not praise an idea because it uses AI or is easy to build. Explain whether AI is necessary and what works without it.
